# KNOXY TEAM para Windows

Downloads oficiais do aplicativo da comunidade [KNOXY TEAM](https://knoxyteam.quest/app).

Os instaladores, a versão portátil e os hashes de integridade estão em Releases. Este repositório distribui somente o aplicativo; o código da plataforma permanece privado.

Requer Windows 10/11 x64 e conexão com a internet. O acesso à comunidade depende de uma conta aprovada. A versão 0.2.0 não tem assinatura digital de editor.
